# Medical Advance Project

An advanced medical analytics starter project built with Streamlit. It simulates patient records, predicts chronic disease risk, and explains why a patient is marked as low, medium, or high risk.

## Features

- Synthetic medical dataset generator
- Risk prediction using a machine learning pipeline
- Interactive single-patient assessment form
- Population dashboard with key clinical insights
- Transparent score breakdown for explainability

## Project Structure

- `app.py` - Streamlit user interface
- `data.py` - synthetic medical data generation
- `model.py` - model training and risk explanation
- `requirements.txt` - Python dependencies

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Use Cases

- Student final-year medical AI project
- Demo for predictive healthcare analytics
- Base project for adding real hospital datasets later

## Important Note

This project is for education and prototyping only. It does not provide medical advice and should not be used for diagnosis or treatment.
